Save reels from Facebook on your iPhone

iPhones don't let web apps appear in the share menu, so a free Apple Shortcut does it instead. Make your own key below, then follow the steps. Each person sets this up on their own phone.

Web address for the Shortcut
apikey header
Your Shortcut key
  1. Open the Shortcuts app, tap +, and name the shortcut Save to Reel Shelf.
  2. Tap the ⓘ button (or the shortcut's name, then Details) and turn on Show in Share Sheet. Under share sheet types, keep only URLs and Text.
  3. Add the action Get URLs from Input, using Shortcut Input.
  4. Optional: add Ask for Input with the prompt Category? so you can label the reel as you save it.
  5. Add Get Contents of URL. Paste the web address above. Tap Show More, set Method to POST, and add a header named apikey with the apikey value above.
  6. Set Request Body to JSON and add three Text fields: key = your Shortcut key, link = the URLs variable, category = Provided Input (or leave it out if you skipped step 4).
  7. Add Show Notification and set its text to Contents of URL. It will say "Saved to Reel Shelf" or "Already on your shelf".
  8. In Facebook, tap Share on a reel, then More (or the ••• row), and pick Save to Reel Shelf. The first time, iPhone asks to allow the connection; tap Always Allow.
